What it does

HuntMail {{.Version}}{{with .Running}} · yours runs {{.}}{{end}}

HuntMail is a catch-all inbox that runs on your own Cloudflare account: every address on your domain works, so each signup can have its own, and HuntDeck shows the mail on the Email page and each program's Email tab. The free plan is enough. Use a domain you don't get other mail on.

HuntDeck sets it up with Cloudflare's API: a D1 database, the HuntMail Worker on your workers.dev address, its private address and API key (saved here, encrypted), and the domain's Email Routing, with its catch-all pointed at HuntMail. Run it again to add a domain or to update HuntMail; it keeps your settings and key.

It needs an API token: in Cloudflare, My Profile › API Tokens › Create Token › Create Custom Token, with:

{{range .Permissions}}{{end}}
{{index . 0}}{{index . 1}}

Zone Resources: your domain. Account Resources: your account. HuntDeck uses the token for this run only and doesn't keep it; you can delete it in Cloudflare afterwards.
